# Fixture provenance and licensing

The human-readable text, document structure, and small pixel patterns created for this directory are original work dedicated to the public domain under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). They may be copied, modified, and redistributed without attribution.

`corpus.json` is the machine-readable record of every real producer document here: its application and version, operating system, packages, fonts with hashes, independent references, the commands that regenerate them, and every measured difference from those references with its classification. `scripts/corpus.ts` validates it in `pnpm test` and rejects an undocumented `real/` document. See `docs/corpus.md`.

`synthetic/` contains deliberately small RTF files generated by `scripts/generate-reference.py`. Each file isolates a parser or layout behavior except `showcase.rtf`, which combines the supported basics into a redistributable demonstration document. The PNG and JPEG inputs are generated pixel-by-pixel by the same script and embedded verbatim as hexadecimal `\pict` data.

`real/libreoffice-25.2.3.2.rtf` and `real/libreoffice-24.2.7.2-table.rtf` were actually written by the identified LibreOffice versions from their adjacent original HTML sources. `reference/` contains exports made by reopening those RTF files in LibreOffice. Embedded font subsets in the PDF retain their respective font licenses; they are not relicensed as CC0. See `docs/compatibility.md` for exact tools, commands, hashes, and measured geometry.
