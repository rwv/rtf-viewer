# Fixture provenance and licensing

The human-readable text, document structure, and small pixel patterns created for this directory are original work dedicated to the public domain under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). They may be copied, modified, and redistributed without attribution.

`synthetic/` contains deliberately small RTF files generated by `scripts/generate-reference.py`. Each file isolates a parser or layout behavior except `showcase.rtf`, which combines the supported basics into a redistributable demonstration document. The PNG and JPEG inputs are generated pixel-by-pixel by the same script and embedded verbatim as hexadecimal `\pict` data.

`real/libreoffice-25.2.3.2.rtf` was actually written by the identified LibreOffice version from the adjacent original HTML source. `reference/` contains exports made by reopening that RTF in LibreOffice. Embedded font subsets in the PDF retain their respective font licenses; they are not relicensed as CC0. See `docs/compatibility.md` for exact tools, commands, hashes, and measured geometry.
