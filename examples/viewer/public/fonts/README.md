# Bundled test fonts

These local fonts keep measurement and paint on the same known files in the example and browser tests.

- Liberation Serif and Liberation Sans files are from Debian package `fonts-liberation` version `1:2.1.5-3`. See `LIBERATION-LICENSE.txt`.
- FreeSans is from Debian package `fonts-freefont-ttf` version `20211204+svn4273-2` and supplies the Chinese glyph fallback. See `FREESANS-LICENSE.txt`.

The font files keep their upstream licenses; the repository's license does not replace them.
